Ejemplo de cómo se ve el muro embebido en una página externa

📋 Instrucciones

Este es un ejemplo de cómo se vería el muro de testimonios embebido en tu sitio web.

⚠️ Importante
Reemplaza df4c7ca5-5107-4a13-a614-68664007bf57 con el ID de tu organización. Puedes obtener el código personalizado desde el dashboard en /dashboard/embed

Parámetros disponibles:

  • theme - light o dark
  • card - base, minimal, detailed, compact
  • color - Color primario en formato hex (ej: %233b82f6)

Código usado en esta página:

<div id="testimonials-wall"></div> <script> (function() { const iframe = document.createElement('iframe'); iframe.src = 'http://localhost:3000/w/df4c7ca5-5107-4a13-a614-68664007bf57?theme=light&card=base&color=%233b82f6'; iframe.style.width = '100%'; iframe.style.border = 'none'; iframe.style.minHeight = '600px'; iframe.id = 'testimonials-wall-iframe'; document.getElementById('testimonials-wall').appendChild(iframe); // Auto-resize window.addEventListener('message', function(e) { if (e.data.type === 'testimonial-wall-resize') { iframe.style.height = e.data.height + 'px'; } }); })(); </script>
